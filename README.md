# Cadence 教員手帳（予定表・時間割・タスク管理）

ローカルサーバー（Node.js / Express）で動かすシンプルな予定表・タスク管理アプリです。
データはすべてブラウザの localStorage に保存されるため、外部のデータベースは不要です。

## 使い方

### 1. Node.js のインストール（未インストールの場合）

このPCには Node.js が見つかりませんでした。以下からインストールしてください。

- https://nodejs.org/ （LTS版を推奨）

インストール後、ターミナルを開き直して `node -v` で確認できます。

### 2. 依存パッケージのインストール

```bash
cd calendar-task-app
npm install
```

### 3. サーバー起動

```bash
npm start
```

起動後、ブラウザで以下にアクセスしてください。

```
http://localhost:3000
```

## 機能（v2：教員手帳）

- **1日**：その日の予定・行事、時間割（その日だけの変更もできる）、期限が来たタスク、メモ、児童ごとのメモ、これから7日間の予定
- **月**：月〜金（設定で土日も）のカレンダー。祝日、行事の帯、予定、タスクの期限、時間割を表示。月の行事一覧つき
- **時間割**：週の時間割表。「基本の時間割」（曜日ごと）と「この週」（1日だけの変更）を切り替え。週の時数を自動で数える
- **タスク**：期限・種類・優先度・メモ。期限切れ／きょう／1週間以内…に分けて表示。編集・まとめて削除
- **設定**：校時数・給食の位置・各校時の時刻、時間割のボタン、予定の種類（色と「行事」扱い）、タスクの種類、児童の呼び名、テーマ、データの書き出し／読み込み

前の版（v1）のデータが同じブラウザにあれば、最初に開いたとき自動で引き継ぎます（v1のデータは消しません）。

## 保存場所

- GitHub Pages 版：その端末のブラウザ（localStorage）に保存
- claude.ai の Artifact 版：同じアプリを claude.ai で開くと、アカウントのクラウドに保存され、iPhone・iPad・PCで同期します

## ファイル構成

```
docs/
├── index.html            # アプリ本体（HTML・CSS・JSを1ファイルに）
├── manifest.webmanifest  # ホーム画面に追加したとき用
├── icons/
└── shugo-jutsugo-slot.html  # 別アプリ（主語・述語スロット）
```

## GitHub Pages での公開
このアプリはサーバー側にAPIを持たず、データもすべてブラウザの localStorage に保存する構成のため、`docs/` フォルダをそのまま GitHub Pages で公開できます（リポジトリの Settings → Pages → Source を `main` ブランチの `/docs` に設定）。

## 補足

- データはブラウザ単位（localStorageのため）で保存されます。別のブラウザ／別のPCでは共有されません。
- Node.js を入れずに試したい場合、`docs/index.html` を直接ブラウザで開いても動作します（ただし一部ブラウザではセキュリティ設定によりローカルファイルの動作が制限されることがあります。その場合は Node.js での起動をおすすめします）。
