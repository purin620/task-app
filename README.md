# 予定表 & タスク管理アプリ

ローカルサーバー（Node.js / Express）で動かすシンプルな予定表・タスク管理アプリです。
データはすべてブラウザの localStorage に保存されるため、外部のデータベースは不要です。

## 使い方

### 1. Node.js のインストール（未インストールの場合）

このPCには Node.js が見つかりませんでした。以下からインストールしてください。

- https://nodejs.org/ （LTS版を推奨）

インストール後、ターミナルを開き直して `node -v` で確認できます。

### 2. 依存パッケージのインストール

```bash
cd calendar-task-app
npm install
```

### 3. サーバー起動

```bash
npm start
```

起動後、ブラウザで以下にアクセスしてください。

```
http://localhost:3000
```

## 機能

- 📅 月表示カレンダー（前月・次月・今日へ移動）
- 予定の追加・編集・削除（タイトル・日付・時刻・メモ・色ラベル）
- ✅ タスク管理（タイトル・期限・優先度、完了チェック、フィルター：すべて/未完了/完了）
- カレンダー上に予定・タスクのバッジ表示
- データはブラウザの localStorage に自動保存（サーバー再起動やページ再読み込みでも消えません）

## ファイル構成

```
calendar-task-app/
├── server.js          # Express サーバー（静的ファイル配信）
├── package.json
└── public/
    ├── index.html
    ├── style.css
    └── app.js          # カレンダー・タスクのロジック（localStorageに保存）
```

## 補足

- データはブラウザ単位（localStorageのため）で保存されます。別のブラウザ／別のPCでは共有されません。
- Node.js を入れずに試したい場合、`public/index.html` を直接ブラウザで開いても動作します（ただし一部ブラウザではセキュリティ設定によりローカルファイルの動作が制限されることがあります。その場合は Node.js での起動をおすすめします）。
